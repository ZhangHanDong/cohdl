# 第 4 课：第一块 CoHDL 小板

> **定位**：走完一个小电路从源码到 PCB、再到制造文件的流程。前置：[第 3 课](03-functions.md)及[连接模型](../cohdl/connections.md)。教材：任务说明，尚未选料、画板或投产。

小板选用按键、状态灯和调试连接器，作为后续手表开发原型的辅助板。先确定它与主控如何连接、工作电压、LED 目标电流、按键逻辑、连接器方向和板框，再选择真实器件。

## 操作顺序

1. 在独立练习工程中定义顶层连接，把重复电路按现有 `fn` 组织。先用显式调用，不等待循环语法。
2. 每个器件明确 part、封装和引脚映射；依赖用 manifest 和 `cohdl.lock` 固定，检查真实 footprint，而不是只看器件名称。
3. `check` 后 `build --emit kicad_pcb`。逐项理解 `.net`、BOM、`design.lock` 和生成的板文件。
4. 把生成板复制到 `pcb/`，建立配套 KiCad 工程与制造规则，完成放置、布线、铜区与丝印。
5. 保存最终板，运行 DRC，核对 CoHDL 元件/网络与 PCB pad 的对应；检查未连接项、警告和排除项。
6. 导出 Gerber、钻孔及所需装配资料，在查看器中复查。按实际装配范围记录是否需要 PCBA。

命令与文件职责详见 [从 check 到实际 PCB](../cohdl/pipeline.md)。尚未选定具体电路，因此这里不提供看似可投产的占位 BOM。

## 观察 M1 的真实缺口

通用按键或电源 helper 应能被不同主控使用。如果必须把具体 MCU 藏进通用库才能连接输出，记录最小复现；不要只为绕过接口限制增加虚拟物理器件。既有能力与候选方案见 [语言里程碑](../cohdl/milestones.md)。

## 验收与沉淀

留下一个完整小板工程、最终 DRC、逻辑/物理连接核对和制造文件；你能解释一个位号如何贯穿源码、BOM 和 PCB。可以把小板随手表原型一起打样，制造文件完成与实板测试分别记录。
