# 语言项与 PCB 事实的完整对照

> **定位**：一张总表。每个 CoHDL 语言项对应它建模的 PCB 事实，并注明编译器在哪一步检查什么、不保证什么。前两部分是已接受并实现的语法，基线 CoHDL 0.7.0 / main `0e3d770`；第三部分是 M2 提案，状态 Proposed，2026-09-12 选定候选 A，候选 B 延后。逐项语法见本组其他章节。

## 一条贯穿的原则

每个语言项都放在「某个检查刚好能局部判定」的那一层：trait 满足与否在写 `impl` 时判定，泛型约束在实例化时判定，引脚义务要等 `design` 装配完才能判定，四条残余 DRC 要看整张连通图。判定阶梯不是事后整理出来的顺序，它是这些抽象各自判定时机排出来的顺序。

反过来，凡是某一层判定不了的，语言就不假装能判定。抽象的边界就是承诺的边界，所以每张表都有「边界」一列。

关于 `trait` 为什么不叫 Shape：它用形状陈述要求，但成员资格靠 `impl` 显式授予（名义类型，形状相同不算），名字本身还承载语义（D002 按 `Polarized` 这个名字触发）和身份（泛型约束、子 trait 关系都引用名字）。形状没有身份，两个相同的形状就是同一个形状。

## 已实现：从器件到电路

**类型层：把数据手册变成类型**

| 语言项 | 对应的 PCB 事实 | 检查时机与边界 |
| --- | --- | --- |
| 11 种单位类型 `3.3V` `100nF` `1kohm` `0.8mm` | 元件参数、额定值、几何尺寸 | 写下即定型，零强制转换。裸数字 E111/E113，单位错 E110/E112。不做任何算术，不知道数值是否合理 |
| `trait` | 元件类别：电阻、电容、二极管、IC、连接器 | 声明要求（引脚角色、规格字段、位号前缀），成员资格由 `impl` 授予。名义类型，形状相同不算 |
| `device` + `pins` | 数据手册的引脚表 | 引脚号、六种电气角色、`required`/`optional` 义务。角色喂给 D003/D004，义务在最终装配时穷尽检查 |
| `spec` | 参数栏：容值、耐压、电阻值 | 单位类型化。只有 `voltage_rating` 被 D001 用来和网络电压比较，其余字段只做类型检查 |
| `impl Trait for Device` | 库管理员的分类判断 | 声明时按名字匹配引脚和字段，缺父 trait 是 E302。不核实这颗料真能当那类用 |
| 泛型 `<C: Capacitance>` | 一族只差参数的器件 | 单位类型参数，替换时零强制转换 |
| 泛型 `<D: Capacitor>` | 「任何一颗电容都行」的可替换性 | trait 约束，实例化时查 `impl`，缺则 E403 |
| `variants` + `pins[V]` | 同一芯片的不同封装 | 封闭集合，每个变体必须有引脚表；实例化必须选 `[V]` |

**物料与几何层：从类型到能买、能焊的东西**

| 语言项 | 对应的 PCB 事实 | 检查时机与边界 |
| --- | --- | --- |
| `part` + `primary`/`alt` | BOM 行、AVL 替代料 | 器件必须完全具体，`primary` 必须有 MPN 和封装符号。`build` 时无物料的实例 E801 |
| `pad` | 一个焊盘的铜、阻焊、钢网、钻孔 | 形状 rect/circle/oval/annulus，槽孔、圆角、切角、钢网开口、阻焊外扩。E805。不检查可焊性 |
| `footprint` + `pad N at` | 封装、land pattern | 焊盘编号集合必须等于器件引脚号集合，E807；同一编号可多块铜 |
| `courtyard` / `silkscreen_ref` / `silkscreen` | 外框、位号文字、丝印图形与极性标记 | 标记引用的焊盘必须存在。不检查标记方向是否真对着阴极 |
| `mount_hole` / `window` | 定位孔（NPTH）、板上开窗 | 编号独立于焊盘，不对应引脚 |
| `#[doc]` | 数据手册链接 | 从不打开文件 |

**电路层：真实元件和连接在这里产生**

| 语言项 | 对应的 PCB 事实 | 检查时机与边界 |
| --- | --- | --- |
| `design` | 一块板 | 封闭世界。所有展开完成后做一次引脚义务穷尽检查 |
| `inst` | 一个位号、一行 BOM 数量 | 按 part 名或精确匹配绑定物料 |
| `inst x: [T; N]` | N 个同类元件 | 每个元素是完整实例，`x[i]` 引用，越界 E202，裸写 E211。目前 N 和 i 必须是字面量 |
| `net NAME [5V\|gnd]: …` | 网表里的一个节点 | 同一引脚出现两次即合并。方括号是唯一的电气事实，名字不是；注解冲突报错 |
| `x[0..=3].PIN` 扇出 | 多个引脚接同一节点 | 只是逐个元素的缩写，只能在 net 成员里用 |
| `nc` | 「我看过手册，这脚可以不接」 | 让缺失成为显式事实，义务检查才能穷尽。不核实这个判断 |
| 位号与 `design.lock` | 丝印上的 R1、C2 | 路径不变则位号不变；删除进墓碑，不复用。`fn` 路径含调用序号，换顺序会换位号 |
| `#[designator]` `#[intent]` `#[placement_hint]` | 位号覆盖、设计意图、放置提示 | 第一个决定位号，后两个纯数据 |
| 四条残余 DRC D001-D004 | 超压、极性接反、驱动端悬空、驱动端打架 | 只这四条，因为只有它们要看整张连通图。不会有第五条 |

**复用层：写一次用多次**

| 语言项 | 对应的 PCB 事实 | 检查时机与边界 |
| --- | --- | --- |
| 模块、`use`、`pub` | 库的目录结构 | 文件树即模块树，跨包需 `pub`，E207-E209 |
| `fn` | 反复出现的小片段：去耦、上拉 | 调用即展开，参数是 `Pin`、trait 约束的实例、单位泛型。每次调用新增体内全部元件。无端口、无稳定路径、不能外部放置。已知缺陷：数组元素作实例参数报 E202 |
| `subdesign` + `ports` | 功能模块：电源段、USB 前端 | 编译器强制的边界：电气只走端口（E1301-E1303、E1306），保留具名路径，可嵌套（递归 E1304），可数组，可泛型，自带默认布局 |
| `place a.b.c` 点路径 | 外层微调模块内一颗元件的位置 | 唯一被允许的内部访问，且只限放置 |
| 包、`cohdl.lock`、注册表 | 库的版本与分发 | 精确版本加内容哈希，每次编译先验哈希 |

**布局事实层：作者知道、编译器只转交**

| 语言项 | 对应的 PCB 事实 | 检查时机与边界 |
| --- | --- | --- |
| `layout { place … rotate … side … }` | 坐标、角度、正反面 | 目标存在、不重复（E1007），角度 0-359，翻面由输出端镜像。不检查重叠 |
| `board_outline: "x.dxf"` | 机械工程师给的板框 | 只取一条闭合折线，E1006 |
| `net_class` `diff_pair` `length_match` | 布线要求：网络类、差分对、等长 | 引用的网络必须存在。不验证是否达成 |
| 七个物理属性 `#[ground]` `#[bypass]` … | 给 Quilter 的物理约束 | 单位和引用检查（E110、E1009），产出八个 CSV |

## M2 提案：候选 A（Proposed）

这一层的 PCB 对应物只有一个：**一族只差一个数的板子**。十路还是十二路 RC，13 颗还是 16 颗灯，5 列还是 6 列的网格。今天这些都要逐条手写；M2 让作者写规则，编译器按规则展开，展开出的每个元件和连接接受和手写完全相同的检查。

下表全部是提案语法，未实现，不能在当前编译器上运行。完整文本见 [M2 中文导读](../programming-proposal.md)。

| 语言项（提案） | 对应的 PCB 事实 | 检查时机与边界 |
| --- | --- | --- |
| `Int`、`Length` 表达式 | 数量、下标、间距 | Int 是 64 位结构整数，不是第十二种单位；Length 精确定点，`1mm / 3` 不能精确表示就拒绝。`10mm + n` 是错，`10mm + n * 4mm` 对。E1401-E1403 |
| `const N: Int = 10`、`const PITCH: Length = 4mm` | 板子的参数 | 局部常量，不导出，不能读引脚电压或规格 |
| `fn f<const N: Int>`、`subdesign Bank<const N: Int>` | 参数化的库单元：N 路驱动、N 通道滤波 | 复用 RFC-007 的替换机制，不引入第二套泛型 |
| `[T; N]`、`x[n + 1]`、`x.len` | 数量随参数变、按公式定位的元素 | 长度必须为正（E211），每个实际下标查边界（E202）。`.len` 是唯一的新查询 |
| `for links: n in 0..N { net _: leds[n].DOUT, leds[n + 1].DIN }` | 菊花链、N 路接线 | 半开区间，`a == b` 为空，`a > b` 是 E1404。候选 A 的循环体只允许 `net`、`nc`、`fn` 调用、常量、嵌套循环 |
| `layout { for grid: n in 0..N { place x[n] at (10mm + (n % 5) * 4mm, …) } }` | 网格放置 | 坐标用同一个求值器，规则同手写 `place` |
| 循环标签与身份 `Board::__for_links_3::…` | 扩容后旧位号不变 | 帧由标签加整数值标识，不按源码顺序。数组元素身份不变；标签是否必须仍在 RFC 附录 A 待决 |
| 分阶段检查 | 「写错单位」和「第 7 路越界」是两种错 | 定义时查类型，绑定后查数值，装配后查义务。空循环也要过静态检查 |
| 展开预算 | 防止一个数字撑爆板子 | 10 万次迭代、100 万个工作项、64 层帧，走完整展开图，超出是确定性硬错误 E1405 |

候选 B（循环体内直接 `inst`/`subdesign`）延后；配置分支、电气公式、自动选料分别是 M3、M4 的事，不在 M2。

## 没有语言项的部分

这些是 PCB 里真实存在、CoHDL 有意不建模的东西。它们要么交给伙伴工具，要么是下一个 RFC。

| PCB 事实 | 现状 |
| --- | --- |
| 走线、铺铜、过孔 | 伙伴工具的事，语言只声明要求（`net_class`、`diff_pair`、阻抗） |
| 叠层、板厚、铜厚、工厂能力 | IPC-2581 输出一个固定的名义双层叠层；语言层没有可配置模型，是下一个真正的缺口 |
| 间距、重叠、可制造性 DRC | KiCad 或 Quilter 的 DRC |
| 工作电流、功耗、分压、截止频率 | 语言不算。M3 才讨论电气公式 |
| 「这两路本该独立」这类设计意图 | 类型允许的短接照样通过，需要独立拓扑对照 |
