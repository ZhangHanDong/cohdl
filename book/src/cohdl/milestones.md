> **定位**：说明课程如何提供语言需求和验收样例。前置：[模块与复用](reuse.md)。本章描述研发路线；未实现语法不是当前教程。

| 里程碑 | 当前基础 | 研发目标 | 手表提供的样例 |
| --- | --- | --- | --- |
| M1 组合与复用 | 文件模块、fn，以及 main `ab44257` 的 subdesign 端口/层级/布局/数组 | 用真实功能区验证接口独立性和布局复用，补工具与规格缺口 | 电源、主控、显示、传感器由顶层组合 |
| M2 编译期编程 | 数组实例、字面量下标、net fan-out | 有界循环、常量/索引表达式、稳定展开规则 | 相同输入通道或规则化测试点 |
| M3 参数化选料 | 带单位规格、固定 part、精确匹配与包锁 | 经核对的电路配方、有限目录选择、计算说明 | 电源树、负载预算、适用阻容选择 |

2026-09-08 更新：RFC-032 subdesign 已合入 main，不再只列为未来提案。[两路 RC 实验](subdesign.md)已验证端口连接、独立元件和整组放置覆盖。M1 进入基于已实现能力的应用验证；这不表示手表接口设计或所有工具呈现均已完成。M2–M4 仍按各自目标推进，subdesign 泛型传参不等于自动计算和选型。

已有实际证据：[Sonde 完整模型](sonde-case.md)用三次 `buffered_path` 调用复用连接，展开后与原板 25 个元件、26 个连接分区一致。完整 build 的物料缺口、三态角色不支持、任意 `supply_min` 字段未形成检查等结果，也在该章逐一记录；这份实验只覆盖各里程碑的一部分，不把所有目标标成完成。

## 两组独立语言实验

2026-09-08 已起草 [M2 编译期可编程能力 RFC](programming-proposal.md)：在 Accepted 数组和 subdesign 基础上，设计有限循环、整数索引与精确长度表达式，并显式评审泛型、身份、诊断和工具的一致性。它仍为 Proposed，未改变下文未来语法的状态；当前语法的 LED 对照例子已通过 check。

2026-09-12 已选择 A 范围：计算数量/索引/位置，重复接线与合法放置，并保留 effectful fn 调用；循环体直接声明 inst/subdesign 的 B 方案延后。标签与区间拼写尚未定稿，见[本次记录](../learning/2026-09-12-m2-scope-a.md)。

**LED 链**用于验证十个元素应产生九条相邻连接，以及单元素、越界等情况。**单路/十路 DC/DC**用于验证定义复用、独立输出、总功率预算和参数化。手表按自己的功能选电路。

未来循环的目标语义可写成下面的提案说明。**当前编译器不支持这个 `for`、`.len` 或计算索引；不作为可执行例子。**

```text
inst leds: [LED_XXOO; 10]
for n in 0..(leds.len - 1) {
    net _: leds[n].DO, leds[n + 1].DI
}
```

半开区间意图生成 n=0…8。具体语法、器件首尾 pin 义务和错误规则需在 RFC 中定义。

## 为什么 M3 不能只是让 AI 给出料号

当前 part 绑定按 device、variant 和具体规格匹配，多候选采用确定性的命名排序，不是成本/性能优化。配方需要保存适用输入、公式、离散值、容差、候选目录与选择策略。库存和价格可以参与采购，但不能让同一 source + lock 的离线构建每天换料。

手表电池供电的拓扑应按实际范围选择；12V→5V 配方只在自己的适用域内有效。输入限制和必要检查随配方交付，不能等 M4 才处理不支持的参数。

## 为什么 M4 需要“未知”

没有支路负载模型，就不能从 net 名称算出实际 pin 电流；没有启动状态模型，也不能断言上电顺序正确。通用契约要说明事实来源、单位、条件、检查阶段，以及缺少事实时如何报告。

既有四条 residual DRC 的边界保持不变，新增语义先按规范决定属于类型检查、part 绑定后检查还是其他明确阶段。

## 学完一课怎样提出语言需求

留下原始电路、当前能编译的表达、遇到的具体困难、期望的新表达和必须保持的元件/连接结果。相关入口：[第 3 课](../course/03-functions.md)、[第 5 课](../course/05-watch-prototype.md)、[第 6 课](../course/06-power-contracts.md)。记录模板见 [学习记录](../learning/template.md)。

当前 AST 能力参照 [src/ast.rs](https://github.com/conol-ai/cohdl/blob/ab44257/src/ast.rs)，现有 DRC 参照 [src/drc.rs](https://github.com/conol-ai/cohdl/blob/ab44257/src/drc.rs)。完整研发路线在仓库 `docs/roadmaps/2026-09-07-language-to-production.md`；本书随已接受、已实现、已验证的进展更新。
