# 2026-09-07：变量与 export

对应章节：[第 0 课](../course/00-workbench.md)。状态：讨论变量作用域并修订教材；环境配置与 Konnect 实操尚未完成。

用户阅读路径变量定义后提出：“这应该是 export 吧”。当前课程中，`cd "$KONNECT_SRC"` 等命令由同一个 shell 展开变量，普通赋值已经可以满足这种用法。`export` 进一步让随后启动的子进程从环境中读取变量。

教材已将三条路径定义统一为 `export NAME="..."`，并解释它不会自动持久化到新终端，也不会更新已有进程。这一修改方便后续脚本读取路径，同时保留原来写法为何有效的说明。

本次没有替用户执行这三条命令，也没有确认用户终端或 Codex 进程中的变量状态。用户复述与完整工作台验收仍待实操；下一步继续 [第 0 课](../course/00-workbench.md) 的副本和连接核对。
