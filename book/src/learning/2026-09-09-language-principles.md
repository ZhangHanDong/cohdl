# 2026-09-09：沉淀语言设计原则与哲学

用户在 M2 RFC 草案之后提出：为保证语言演进的整体一致性，先沉淀语言设计原则和哲学。

本次阅读 Constitution、概念模型、原则约束、一致性矩阵、RFC 流程、演进治理，以及相关单位、引脚、身份、数组、泛型和 subdesign RFC；沿用已取得的 `ab44257` 基线，不将其称为今天最新远端版本。

新增 `docs/language-design-principles.md`，把既有哲学归纳为十条带来源、应用判断和评审问题的原则，并提供 RFC 评审卡。配套[语言设计原则章节](../cohdl/language-principles.md)引用同一正文；历史设计总览译文继续保留其原有语境。

主要澄清包括：正确性优先于书写便利；结构检查应在信息充分时发生；确定性不同于跨编辑的身份稳定；显式默认允许复用；required/optional/nc 的义务不同；check、物料构建、需求符合与实板验收分别表述。

三路只读复核后，将 gradeability 明确译为“机器可检验性”；补齐评审卡中的依据、条件和未覆盖范围；按 main 的 `pipeline::resolve_board_outline` 及 CLI 调用核对，把引用的 DXF 等资源加入复现输入说明。固定资源是复现要求，不声称现有依赖锁已经覆盖项目 DXF 内容。
