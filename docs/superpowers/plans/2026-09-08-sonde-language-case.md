# Sonde 整板解读与 CoHDL 实验

用户要求：完整解读当前 KiCad 练习板，并用 CoHDL 描述、检查、编译和评估语言改进点。沿用已授权的 Book 学习工作流。

## 约束

- 以本次 Konnect 导出的 `book/src/learning/evidence/2026-09-08-sonde-full/sonde.net` 为连接真值。
- 忠实保留 25 个实例、数值、引脚映射、26 个有连接的网络分区、16 个显式未连接引脚。网络名称可以规范化，但必须独立比较端点集合。
- 不编辑原始 KiCad 文件，不修改编译器，不编造采购料号或硬件测量。
- 采用已实现语法；类型/连接检查、生产物料绑定、物理验证分别报告。
- 原板缺采购数据时，实际运行 build 并记录真实错误；不绕过门槛伪造可投产成功。可补一个有真实物料来源的最小 build 对照，明确其范围。
- 复用优先研究三条缓冲通道的 fn；三态行为如果不能忠实建模，明确显示抽象边界。
- 只更新本次 Book、示例和证据；不提交既有未提交工作。

## 执行

1. 已完成：Konnect 检查版本、GUI/IPC、打开路径、全部器件/焊盘/网络、ERC/DRC，导出原理图及网表，保存前后源文件哈希一致。
2. 实现任务：`book/examples/sonde/` 内建立 CoHDL 模型和独立对照验证，执行 check/build/fmt 与有意义的失败案例；实现报告写入 `/tmp/cohdl-sonde-implementation-report.md`。
3. 并行文档任务：整板功能、电源、三条输出通道、回读/拉低通道、接口、全部元件与检查边界；写课程章节。
4. 集成：补 CoHDL 实验章节、学习记录、进度、目录和 README 命令；运行实际示例和两项 Book 检查。
5. 三个独立只读审阅：电路事实、模型与测试、初学者结构；处理有证据的问题，复核受影响检查。

篇幅按课程已有大纲，分为整板解读与 CoHDL 实验两页，不要求学习者一次掌握。
