# CoHDL Book 的范围与章节安排

依据：用户已确认的 [手表学习路线](roadmaps/2026-09-07-watch-learning-and-language-milestones.md)，以及 2026-09-07 使用 mdBook 组织课程、随学习逐步完成书籍的要求。用户明确更正项目名为 CoHDL，书名统一为 CoHDL Book。

## 本次交付

一个放在 `book/` 的中文 mdBook，可本地构建、搜索和预览。使用本机已有的 mdBook 0.5.3，构建工具独立于编译器依赖。课程、知识章节和学习记录放在同一本书里，通过相对链接互相连接。

本次写作范围是课程初版：前 3 课提供可执行的操作步骤，后续课提供任务、准备条件和验收说明；知识章节讲解已实现的基础，配一个真实编译检查的最小例子。每页围绕一个学习问题，以数百至约 1500 中文字为编辑目标，不采用源码分析长篇的默认篇幅。后续根据实操继续扩写，不虚构未执行实验的数据、截图或通过结论。

## 目录与职责

| 区域 | 页面 | 职责 |
| --- | --- | --- |
| 导读 | index、学习路线 | 两条阅读路径、约定、课程依赖与终点 |
| 实操课程 | 工作台、认图、修改检查、功能复用、小板、手表原型、电源契约、制造测试 | 按一个真实设计问题组织；每课链接对应知识与学习记录 |
| CoHDL 知识 | 连接模型、组合复用、构建到 PCB、语言里程碑 | 可独立查阅；当前语法与未来提案分开 |
| 语言设计研究 | 设计原则、产品边界、里程碑、M2 工作稿及历史译本、开源对照 | 供参与语言开发时阅读；提案和历史版本不进入当前语法教程 |
| 学习记录 | 进度、记录模板、本次起点 | 学习状态与教材编辑状态分别记录；保留未验证事项 |
| 附录 | 术语、资料来源、贯穿示例 | 定义集中维护，来源有版本，跨章节解释一次操作的全过程 |

课程中的“功能复用”先读 multichannel 和 RoyalBlue，再讨论 CoHDL 模块；“构建到 PCB”解释 `.net`、BOM、`design.lock` 和原生板之间的关系。相同源码只在知识章节展开，课程链接过去。十路 DC/DC 和 LED 链保留为独立语言验收，手表按实际功能采用语言能力。

2026-09-08 补充：Sonde 三路 fn 实验提供了更近的入门案例；main RFC-032 的 subdesign 另设[两路 RC 专章](../book/src/cohdl/subdesign.md)，用实际源码解释逻辑端口、独立元件和整组布局，再接入第 3 课与 M1。历史 Sonde 结果和新 main 的验证基线分别保留。

2026-09-09 补充：[语言设计原则](../book/src/cohdl/language-principles.md)承接设计总览与 M2 评审。章节提供速查，展开全文直接引用 `docs/language-design-principles.md`，只维护一份原则指南；指南是对既有规则的归纳草案，不成为新的规范来源。

## 更新规则

2026-09-10 Book 评审修订：保留 demo→手表的实践顺序，给第 3–7 课的任务说明加“课程提纲”目录标记。第 3 课后新增十路 RC 实操课（约 1800–2500 中文字，源码/命令另计），从硬件连接、当前 CoHDL 表达、布局覆盖、扩容、错误实验四层讲清一个例子；配一页诊断指南（约 800–1200 字）。M2 中文概览随英文工作稿更新；旧译本明确作为历史资料保留。学习记录继续逐条可访问，提炼的误解与验证方法回到课程。检查成功和用户掌握分别记账。

每次学习完成后，补记录中的问题、预测、操作、真实输出和复述；再把可复用知识写回课程/知识章节。教材状态与学习状态单独维护；未来语法通过 RFC 接受并实际验证后，才改成当前教程。截图绑定练习副本和版本，制造结论绑定最终 PCB，实测结论绑定板与固件。
